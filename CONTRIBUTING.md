# Contributing

Este projeto é um laboratório de QA.

## Antes de enviar alterações

1. Não inclua segredos.
2. Não inclua dados pessoais reais.
3. Execute as validações disponíveis.
4. Atualize a documentação quando necessário.
5. Não declare testes como executados sem execução real.
6. Diferencie IMPLEMENTADO, PARCIALMENTE IMPLEMENTADO e PLANEJADO.

## Commits

Prefira commits pequenos e objetivos, por exemplo:

- `chore: initialize qa laboratory`
- `docs: add test plan`
- `test: add login test cases`
- `test: document api validation`
- `fix: correct authentication validation`
